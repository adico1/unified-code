# Stage-1 Fixed Point

The bounded Milestone 2 fixed-point operation proves:

```text
trusted Stage0(ROOT.seed) = Stage1-A
generated Stage1-A(ROOT.seed) = Stage1-B
SHA256(complete tree A) = SHA256(complete tree B)
```

Run it with:

```bash
python bootstrap/fixed_point.py \
  --stage0 bootstrap/stage0.py \
  --contract seed/stage0/TRUSTED_INPUTS.json \
  --input-root . \
  --output /tmp/uc-stage1-fixed-point
```

`Stage1-B` is produced by the generated `Stage1-A` runner in a second process,
with only `ROOT.seed.json`, a fixed locale/clock environment, and no source
checkout import path. The proof compares the complete declared nine-file
inventories and every byte. The aggregate identity hashes sorted
`path + NUL + file SHA-256 + newline` records.

Any missing, extra, or changed byte makes the result invalid and emits exact
path, hash, size, and first-differing-byte evidence. Failed work cannot replace
an already published fixed-point proof.

Path, locale, timezone, clock input, JSON record order, and process environment
are either excluded from generated bytes or pinned at the execution boundary.
There are no implementation-file exclusions.

This proves only the generated Stage-1 and root-projection surface. It does not
yet regenerate every tracked repository file from `ROOT.seed`.
